- ***Type***: Optional Rule
- ***Description***:<br>_Optional Rule_ — Your **GM** will decide if they want to add this rule to the game.<br><br>[[SoC • Rules - Skill Checks|Skill Checks]] that normally take **1 hour** can now be performed as **Rituals**. (_This includes [[Medicine]], [[Forging]], [[Intuition]], and [[Arcane]] checks for actions like Healing, Crafting, Identifying Potions, ..._)<br><br>A **Ritual** is a [[SoC • Rules Chapter - SKILLS|Skill Check]] made with **3 [[SoC • Rules - Advantage and Disadvantage|Disadvantages]]**. If you **succeed**, you complete the task using only a single **Action**.<br>If you Fail a **Ritual**, you must spend **1 hour** on the same task, before attempting the same [[SoC • Rules Chapter - SKILLS|Skill Check]] again — this time without any additional [[SoC • Rules - Advantage and Disadvantage|Disadvantages]]. Alternatively, after that hour, you may choose to automatically take a result of **10** instead of rolling.
