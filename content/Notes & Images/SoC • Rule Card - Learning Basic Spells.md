- ***Type***: Rules
- ***Description***:<br>_Once you have some [[SoC • Rules Chapter - NEW CAMPAIGN|Hero Points]] to spend, the simplest way to add **magical** or **supernatural powers** to your character is to learn some [[SoC • Rule Card - Learning Basic Spells|Basic Spells]], and increase your [[SoC • Rules Chapter - ENERGY|Energy]] reserves to use them_.<br><br>Basic Spells can be learned by anybody that wishes to. They don't require any specific [[SoC • Rules Chapter - RUNES|Rune]] to be learned.<br>Every Basic Spell has on the top-right a marker (_[1], [2], [3], ..._) It indicates both how many **[[SoC • Rules Chapter - NEW CAMPAIGN|Hero Points]]** you need spend in order to learn it, and how much **[[SoC • Rules Chapter - ENERGY|Energy]]** it requires to be casted every time.
